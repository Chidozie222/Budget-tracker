Usage notes

Green (#1DD3B0)income, positive numbers, active nav/tab, primary CTA
Red (#F0405B)expenses, negative numbers, destructive actions (logout)
Blue / Indigoneutral stat icons only (today's spend, daily limit)
Orange / Purplecategory icon backgrounds — one hue per category, reused consistently

Typography

Poppins — SemiBoldapp logo, screen titles, balances, card headings
Inter — SemiBoldstat values, transaction amounts, labels
Inter — Mediumbody text, list rows, buttons
Inter — Regulartimestamps, helper text, captions

Type scale

26px / 600Balance / hero number (Poppins)
20px / 600Screen title (Poppins)
14–15px / 600Card titles, budget names
13–13.5px / 500Row labels, list items
11–12px / 400–500Secondary text, timestamps, captions
9.5–10.5px / 500Nav labels, tiny metadata

Fonts to install

Google FontsPoppins (500, 600, 700) · Inter (400, 500, 600, 700)

Icons

Style used herehand-coded outline SVGs, 2–2.4px stroke, no fill — same family as Lucide / Feather / Tabler
Recommended setLucide — closest match, actively maintained, has a React Native package
Packagenpm install lucide-react-native react-native-svg
Browse icons atlucide.dev
